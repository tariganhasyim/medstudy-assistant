# MedStudy Assistant

An open-source project that helps medical students organize learning objectives, summarize medical references, and generate interactive study materials using AI.

## Features

- Learning Objective Management
- AI Summary Generator
- Flashcard Generator
- Quiz Generator
- Clinical Case Collection
- Study Progress Tracker

## Planned Tech Stack

- Python
- FastAPI
- Streamlit
- OpenAI / Anthropic API
- SQLite

## Roadmap

### Phase 1
- Basic project structure
- Learning objective database
- Markdown parser

### Phase 2
- AI summarization
- Flashcard generation
- Quiz generation

### Phase 3
- Clinical reasoning module
- Web interface
- Export to PDF
